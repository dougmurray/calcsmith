# Calcsmith

A personal engineering calculator for macOS and iPhone, built with SwiftUI from one codebase.

- **Scientific calculator** (default) with results in engineering notation: `4.7e-6` → `4.7μ`, `12000` → `12k`.
- **Formula library**: 104 formulas / 166 solve-variants across 10 topics, ported from
  [analog_engineer_assistant](../analog_engineer_assistant). Searchable; press **Tab** (⇧Tab to go back) to change the subject of the formula.

## Layout

| Path | What |
|---|---|
| `Sources/CalcsmithCore` | Platform-independent logic: expression evaluator, engineering formatter, formula model, search |
| `Sources/CalcsmithCore/Formulas` | One file per topic, generated by `tools/port_formulas.py` |
| `Sources/CalcsmithUI` | SwiftUI views shared by both apps (`#if os(...)` for platform differences) |
| `Apps/macOS`, `Apps/iOS` | Thin `@main` app entry points |
| `project.yml` | XcodeGen spec for `Calcsmith.xcodeproj` |

## Build & run

```sh
xcodegen generate               # after changing project.yml or adding app files
open Calcsmith.xcodeproj        # schemes: Calcsmith-macOS, Calcsmith-iOS
swift test                      # core logic tests
```

To run on a physical iPhone, set your development team in the Calcsmith-iOS target's Signing settings.

## Typing math

Works in the calculator and in every formula input field.

| Input | Meaning |
|---|---|
| `4.7k`, `10u` / `10μ`, `3.3n`, `2M` | SI prefixes (f p n u/μ m k M G T) |
| `1e-3`, `2E6`, `0xFF`, `0b1010` | Scientific, hex, binary |
| `+ - * / ^`, `× ÷ −`, `**` | Operators (`^` is right-associative; `-2^2 = -4`) |
| `10k || 4.7k` or `∥` | Parallel combination: a·b/(a+b) |
| `2π`, `3(1+2)` | Implicit multiplication |
| `5!`, `50%`, `5²` | Postfix factorial, percent, squares |
| `sin cos tan asin acos atan sinh … sqrt cbrt ln log log2 exp abs floor ceil round min max mod atan2` | Functions; `log(x, b)` for base b |
| `db(x)` / `idb(x)` | Voltage ratio ↔ dB (20·log₁₀) |
| `pi π e tau c q kB h eps0 mu0` | Constants |
| `ans` | Previous result; typing an operator right after `=` continues from it |

Formula inputs may also end with the variable's unit: `4.7uF`, `10 kΩ`, `1.6mm`.

## Keyboard (macOS)

| Key | Action |
|---|---|
| just type | Calculator field is focused at launch |
| Return or `=` | Evaluate |
| Esc | Clear |
| ⌘1 / ⌘2 | Calculator / Formulas |
| ⌘F | Search formulas |
| ↑ ↓ in search | Move through results |
| Return in search | Open the selected formula and focus its first input |
| Return in an input | Next input |
| Tab / ⇧Tab | Change the subject (solve-for variable); the current answer carries into the old subject's field |

## Re-syncing formulas

```sh
python3 tools/port_formulas.py ../analog_engineer_assistant Sources/CalcsmithCore/Formulas
```
